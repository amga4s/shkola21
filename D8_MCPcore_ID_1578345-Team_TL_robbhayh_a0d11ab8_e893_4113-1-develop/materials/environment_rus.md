# Python и запуск в Linux

Команды проекта выполняются в терминале из корня репозитория — папки с `README.md`. Для указанного набора зависимостей нужен Python 3.12 или новее. Профиль кампусной подготовки использует Python 3.12.14; при другой версии сначала выполните проверку ниже. Bash-команды активации одинаковы в Linux и macOS.

## Если кампусное окружение уже подготовлено

Скрипт `campus_preflight.py --prepare` создаёт отдельное окружение и устанавливает Python-пакеты. В комплекте подготовки путь задаётся параметром `--venv`; стандартный путь запуска — `$HOME/.venvs/bassein-12-10`. Если техническая поддержка указала другой путь, используйте его.

```bash
source "$HOME/.venvs/bassein-12-10/bin/activate"
python3 -c "import sys; print(sys.executable); print(sys.version)"
python3 check_environment.py
python3 client.py demo
```

Первая команда только активирует существующее окружение. Если файл `bin/activate` не найден, подготовка по этому пути ещё не выполнена. Уточните путь у технической поддержки или создайте личное окружение по шагам ниже. В новом терминале активацию нужно повторить. Для выхода из окружения выполните `deactivate`.

## Если нужно создать личное окружение

Выполните из корня проекта:

```bash
python3 --version
python3 -m venv .venv
source .venv/bin/activate
python3 -m pip install -r requirements.txt -c requirements-campus.lock.txt
python3 -m pip check
python3 check_environment.py
python3 client.py demo
```

`requirements.txt` перечисляет пакеты проекта, а `requirements-campus.lock.txt` ограничивает версии их зависимостей. Команда устанавливает только нужное этому проекту дерево пакетов. Установка требует доступа к разрешённому репозиторию пакетов; при ограниченной сети используйте подготовленное кампусное окружение или обратитесь в техническую поддержку.

Если нет `python3`, версия ниже 3.12 или создание окружения сообщает об отсутствии `venv`/`ensurepip`, нужны системные компоненты. Их название и способ установки зависят от дистрибутива Linux — обратитесь в техническую поддержку с полным текстом ошибки. Python-пакеты устанавливаются внутри окружения; `sudo pip`, `--user` и обход защиты системного Python не нужны.

Папку `.venv/` не добавляйте в Git. Git, редактор и браузер — отдельные программы: `pip` их не устанавливает.

## Первый результат

Демонстрация должна показать товар `hoodie` (цена 500, остаток M — 5) и предусмотренный отказ `PRODUCT_NOT_FOUND` для `missing`. Это настоящий локальный вызов MCP. Доступ к модели, API-ключ и интернет для самого вызова не нужны.

`python3 -m pytest testing/test_example.py -q` проверяет выданный пример. Полная проверка `python3 checks/acceptance.py --project . --profile base` на стартовом шаблоне не проходит: описания и функции с `TODO` предстоит реализовать в заданиях.
